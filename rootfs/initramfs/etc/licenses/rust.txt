Rust standard library and the libc crate

The programs oos-ui, oos-fpgad and oos-update contain the Rust standard library with the code it is built from
(core, alloc, std, compiler-builtins, the unwinder and others) and the crate libc.

(BSD-2-Clause, Apache-2.0 WITH LLVM-exception, NCSA, Unicode-3.0). The complete list, with every copyright notice,
is the file COPYRIGHT-library.html of the Rust toolchain a build was made with (share/doc/rust/ in the toolchain).
