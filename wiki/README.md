# The wiki, kept in the tree

The pages in this folder are the guide for people who use OOS on a scope. They are published as the
[wiki of the repository](https://github.com/dekajoule/oos/wiki) every time a change to this folder reaches main
(`.github/workflows/wiki.yml`, [ADR 0035](../docs/adr/process/0035-every-text-has-one-home-the-wiki-comes-from-the-tree.md)).

- Change a page here, in a pull request, with the change it describes. A page edited on the wiki itself is
  overwritten by the next publication.
- The file name is the title of the page: `First-Steps.md` is "First Steps". `Home.md` is the start page and
  `_Sidebar.md` the list at the side.
- This file is not published.
