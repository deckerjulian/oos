# OOS wiki

OOS is an open operating system for the Rigol DHO800/DHO900: its own Linux kernel and a scope application in Rust, on the scope's SD card, next to the stock system.

![OOS on a DHO924S](https://raw.githubusercontent.com/dekajoule/oos/main/docs/images/pane-spectrum.png)

> **Experimental.** OOS has run on a DHO924S and, by user reports, on DHO804s. Read the [disclaimer](https://github.com/dekajoule/oos#disclaimer) before you install it. Measurements are not calibrated to any standard.
