# Contributing

OOS is meant to grow into a freely available system built together. Everything helps:

- **Test reports**, above all from models other than the DHO924S. Say what worked and what did not.
- **Bug reports:** [open an issue](https://github.com/dekajoule/oos/issues) with the model, the build, and how to repeat it.
- **Code:** start with the [technical documentation](https://github.com/dekajoule/oos/blob/main/docs/README.md) and the [development notes](https://github.com/dekajoule/oos#development). How to build, also on Linux x86-64: [[Building]]. You can run OOS without a scope, see [Try it without a scope](https://github.com/dekajoule/oos#try-it-without-a-scope).

Security issues go through [the security reporting of the repository](https://github.com/dekajoule/oos/security), see [SECURITY.md](https://github.com/dekajoule/oos/blob/main/SECURITY.md).
