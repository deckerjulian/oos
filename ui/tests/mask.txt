# Mask test: create a mask from CH1 (square, passes), then from CH4 with tolerance X 0.04 div (PWM with sweeping duty:
# the falling edges leave the mask, fails), then stop on fail. Menus and items by name (cmd.rs `menu`, `set`, `do`):
# taps at fixed places hit other items when the layout or the text size moves them.
menu Mask
frames 2
shot $S/c0-mask-menu.ppm
set Mask test = On
frames 60
shot $S/c1-mask-pass.ppm
key ch4
frames 5
menu Mask
set Source = CH4
set Tolerance X = 0.04 div
set Mask test = On
frames 60
shot $S/c2-mask-fail.ppm
menu Mask
set On fail = Stop
do Reset counts
frames 60
shot $S/c3-mask-stop.ppm
