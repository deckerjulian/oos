# Getting help

OOS is a free project with one maintainer and a few contributors. There is no paid support, and the vendor does not
support OOS: ask here, not the vendor.

| You want | Go to |
|---|---|
| to install OOS, use it, or go back to the stock system | the [guide][wiki] |
| to ask a question or talk about OOS | the [thread in the EEVblog forum][forum] |
| to report something that does not work | an [issue][new], form "Problem report" |
| to ask for a feature | an [issue][new], form "Wish" |
| to report what a model you own does (a probe, a test) | an [issue][new], form "Report from a scope" |
| to report a security problem | privately, as [SECURITY.md](SECURITY.md) says; not as an issue |
| to report behaviour against the [code of conduct](CODE_OF_CONDUCT.md) | privately, as its section "Enforcement" says |
| to contribute code, docs or measurements | [CONTRIBUTING.md](CONTRIBUTING.md) |

A report is answered faster with the scope's model, the OOS build (the line in `/etc/oos-build`, or System > About),
how OOS was installed, and the steps that show the problem. Leave out serial numbers, MAC addresses and the scope's
address.
